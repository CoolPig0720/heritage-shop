# 第二章 相关开发技术介绍

## 2.1 Spring Boot框架

Spring Boot是由Pivotal团队研发的基于Spring框架的开源Java应用开发框架。该框架采用"约定优于配置"的设计理念,通过自动配置机制和起步依赖特性,有效简化了Spring应用的初始搭建与开发流程。Spring Boot内置嵌入式Web服务器,无需额外部署即可独立运行,大幅降低了应用部署的复杂度。

在本系统中,Spring Boot作为后端核心开发框架,主要承担以下功能:第一,提供RESTful API服务的快速构建能力,通过spring-boot-starter-web依赖实现Web层开发;第二,实现自动配置机制,根据项目依赖自动装配Spring应用上下文,减少XML配置文件;第三,提供统一异常处理机制,通过全局异常捕获器实现错误信息的标准化返回;第四,支持多环境配置管理,便于开发、测试、生产环境的灵活切换。本系统采用Spring Boot 3.2.0版本,基于Java 17开发环境,充分利用了新版本的性能优化与特性支持。

## 2.2 Vue.js前端框架

Vue.js是由尤雨溪于2014年创建的渐进式JavaScript前端框架,专门用于构建用户界面。该框架的核心库专注于视图层,采用自底向上的增量开发设计,具有易于集成和上手的特点。Vue框架通过响应式数据绑定和组件化开发模式,显著提升了单页面应用的开发效率与可维护性。

Vue框架的核心特性主要体现在两个方面:其一,数据驱动视图更新机制,通过响应式系统实现数据与视图的自动同步,开发者仅需修改数据即可触发视图的自动渲染,避免了传统开发中手动操作DOM的繁琐过程;其二,视图组件化架构,将整个页面拆分为独立可复用的组件单元,通过组件的组合与嵌套构建复杂界面,提高了代码的可维护性和复用性。

本系统采用Vue 3.3.4版本进行前端开发,主要应用了其组合式API、响应式系统升级、单文件组件等核心特性,结合Vue Router实现前端路由管理,通过Pinia进行全局状态管理,构建了完整的单页面应用架构。

## 2.3 MyBatis-Plus持久层框架

MyBatis-Plus是在MyBatis框架基础上进行功能增强的持久层开发工具,在保持MyBatis原有特性的前提下,提供了更为便捷的开发体验。该框架遵循"只做增强不做改变"的设计原则,通过内置通用Mapper、条件构造器、分页插件等功能,显著简化了数据库操作的开发工作量。

MyBatis-Plus框架的核心优势包括:第一,内置通用Mapper接口,开发者通过继承BaseMapper即可获得基础的CRUD操作能力,无需编写重复的SQL映射文件;第二,提供Lambda条件构造器,支持以类型安全的方式构建复杂查询条件,避免了字符串硬编码带来的维护困难;第三,集成强大的分页插件,通过拦截器机制自动处理分页查询,简化了分页逻辑的实现;第四,支持多种主键生成策略,满足不同业务场景的需求。

本系统采用MyBatis-Plus 3.5.5版本作为数据持久层框架,主要用于实现用户、商品、订单、非遗项目等核心业务数据的持久化管理。通过@TableName、@TableId等注解实现对象关系映射,利用条件构造器完成复杂查询逻辑,配合Spring Boot的事务管理机制保障数据一致性。

## 2.4 MySQL数据库

MySQL是一款开源的关系型数据库管理系统,凭借其高性能、高可靠性和易用性,已成为Web应用开发领域最为广泛使用的数据库之一。该系统采用结构化查询语言(SQL)进行数据操作,支持事务处理、并发控制和数据完整性约束等核心功能。

本系统采用MySQL 8.0版本进行数据存储与管理,主要技术特点包括:首先,使用InnoDB作为默认存储引擎,该引擎支持ACID事务特性、行级锁定机制和外键约束,有效保障了数据的一致性与完整性;其次,全面采用UTF8MB4字符集编码,支持完整的Unicode字符集,能够正确存储包括生僻汉字在内的各种特殊字符,满足非遗文化产品的数据存储需求;再次,支持JSON数据类型,为存储非结构化数据提供了便利,增强了数据存储的灵活性。

本系统数据库设计严格遵循第三范式,通过合理的表结构设计与索引优化,实现了高效的数据存储与检索。核心数据表涵盖了用户管理、商品管理、订单管理、非遗文化内容管理以及智能定制记录等业务模块,为系统功能的实现提供了可靠的数据支撑。

## 2.5 Spring Security与JWT认证

本系统采用Spring Security结合JWT实现用户认证与权限控制机制。Spring Security是Spring生态系统中的企业级安全框架,提供了完整的认证、授权和安全防护功能。JWT(JSON Web Token)是一种基于JSON的开放标准,用于在网络应用环境间安全地传递声明信息。

Spring Security在本系统中的应用主要包括:通过配置安全过滤器链实现请求拦截与认证处理,采用BCrypt加密算法对用户密码进行安全存储,以及通过方法级注解实现细粒度的权限控制。JWT认证机制采用无状态设计,用户登录成功后服务端生成包含用户信息的令牌,客户端在后续请求中携带该令牌完成身份验证。相比传统的Session认证方式,JWT具有无需服务端存储状态、天然支持跨域请求、便于水平扩展等优势,更加适合前后端分离架构的应用场景。

## 2.6 Element Plus组件库

Element Plus是一套基于Vue 3的桌面端组件库,由饿了么前端团队开发并开源。该组件库提供了丰富的UI组件,涵盖了表单、表格、导航、数据展示等常见交互场景,具有统一的视觉风格和良好的用户体验。

本系统采用Element Plus 2.4.4版本构建用户界面,主要应用了其表格组件实现数据列表展示,表单组件完成用户输入验证,对话框组件处理弹窗交互,以及上传组件实现文件传输等功能。该组件库支持通过CSS变量进行主题定制,本系统据此实现了浅色与深色两种主题模式的切换。同时,Element Plus内置的国际化支持结合vue-i18n实现了中英文双语界面,满足了系统的多语言需求。

## 2.7 Vite构建工具

Vite是由Vue作者尤雨溪开发的新一代前端构建工具,旨在为现代Web项目提供更为高效的开发体验。该工具利用浏览器原生ES模块支持,在开发环境下无需进行打包操作,直接启动开发服务器,实现了极速的冷启动速度。Vite采用按需编译策略,仅在模块被请求时进行编译,避免了全量编译带来的性能损耗。在生产构建阶段,Vite使用Rollup进行代码打包,支持代码分割、Tree Shaking、资源压缩等优化技术,有效减小了最终产物的体积。本系统采用Vite 5.0.10版本,通过合理的配置实现了开发效率与构建优化的平衡。

## 2.8 Pinia状态管理

Pinia是Vue.js官方推荐的状态管理库,作为Vuex的继任者,提供了更为简洁和现代化的API设计。Pinia采用模块化的store设计,每个store都是独立的单元,支持代码分割和类型推断。相比Vuex,Pinia移除了mutation概念,直接通过action修改state,简化了状态管理的复杂度。本系统采用Pinia 2.1.7版本进行全局状态管理,主要用于管理用户登录状态、认证令牌等全局数据,通过持久化存储实现了页面刷新后的状态恢复。

## 2.9 腾讯云AI服务

本系统智能定制模块对接腾讯云混元AI生图服务,实现了文生图和图生图两项核心功能。文生图功能允许用户通过文本描述生成对应的图片,图生图功能则在用户上传参考图的基础上,结合文本提示生成新的图像内容。该服务通过腾讯云提供的Java SDK进行集成,后端配置密钥后发起API请求,采用同步调用结合内部轮询机制等待AI生成完成,最终将生成的图片存储至本地并返回可访问URL。AI生成记录被持久化保存,支持用户查看历史生成记录,为后续的商家定制提供参考依据。

## 2.10 Three.js三维展示

Three.js是一个基于WebGL的JavaScript 3D图形库,用于在浏览器中创建和渲染三维计算机图形。本系统采用Three.js 0.172.0版本结合Google开源的model-viewer组件,实现了非遗产品的3D展示功能。用户可以在商品详情页通过鼠标交互对3D模型进行旋转、缩放操作,获得沉浸式的商品浏览体验。该功能特别适用于陶瓷、木雕等立体感强的非遗工艺品展示,有效增强了用户的购买决策信心。3D模型文件采用glb/gltf格式存储,通过商品表的model_3d_url字段进行关联。

## 2.11 Axios HTTP客户端

Axios是一个基于Promise的HTTP客户端库,适用于浏览器和Node.js环境。本系统采用Axios 1.6.2版本进行前后端数据交互,通过请求拦截器统一添加JWT认证令牌,通过响应拦截器统一处理错误信息和登录态过期跳转。Axios自动完成JavaScript对象与JSON格式的相互转换,简化了数据序列化处理。本系统将所有API调用按业务模块封装,提高了代码的可维护性和复用性。

## 2.12 Redis缓存

Redis是一款开源的内存数据结构存储系统,可用作数据库、缓存和消息中间件。本系统预留了Redis支持,可用于缓存热点数据如首页商品列表和非遗分类树,减少数据库查询压力;实现API限流控制,防止恶意请求;以及在并发场景下通过分布式锁保障数据一致性。当前Redis处于可选配置状态,可根据实际性能需求灵活启用。

## 2.13 Lombok代码简化工具

Lombok是一个Java代码生成工具,通过注解在编译期自动生成样板代码,如getter、setter、toString等方法。该工具通过减少冗余代码提高了代码的可读性和开发效率。本系统主要使用了@Data、@RequiredArgsConstructor等注解,简化了实体类和依赖注入的代码编写。Lombok通过注解处理器实现,不会增加运行时开销,是现代Java开发中广泛采用的效率工具。

## 2.14 Knife4j接口文档

Knife4j是Swagger的增强实现,为Spring Boot项目提供自动化的API文档生成功能。该工具通过读取Controller层的注解信息,自动生成结构化的接口文档,包含接口路径、请求参数、响应格式等完整信息。Knife4j提供了可视化的在线调试界面,支持参数填写、请求发送和响应查看,大幅提升了前后端联调效率。同时支持导出多种格式的离线文档,便于接口文档的归档与分享。本系统采用Knife4j 4.3.0版本,实现了API文档的自动化管理与维护。

## 2.15 本章小结

## 2.15 本章小结

本章系统地介绍了非遗产品智能定制商城系统开发过程中所采用的主要技术栈。后端开发以Spring Boot框架为核心,结合MyBatis-Plus持久层框架和MySQL数据库,构建了稳定高效的数据处理层;通过Spring Security与JWT认证机制实现了安全可靠的用户认证与权限控制。前端开发采用Vue.js框架,结合Element Plus组件库、Vite构建工具和Pinia状态管理,实现了响应式用户界面与流畅的交互体验。此外,系统集成了腾讯云AI服务实现智能定制功能,采用Three.js实现3D产品展示,通过Axios完成前后端数据交互,并利用Knife4j实现API文档的自动化管理。上述技术均是目前业界成熟稳定的主流方案,具有完善的生态系统和丰富的文档资源。通过合理选择和组合这些技术,本系统实现了前后端分离架构、RESTful API设计、AI智能定制、3D产品展示等核心功能,为系统的高效开发和稳定运行提供了坚实的技术保障。
