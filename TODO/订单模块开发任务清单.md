- [x] 加购校验商品存在且上架（`product.status=1`）
- [x] 条目归属校验（只允许操作当前用户 cart_item）
- [x] 数量非法与参数校验错误提示统一走 `BusinessException`
- [x] 下单前校验存在“已勾选且有效”的购物车条目
- [x] 下单时写入地址快照（从收货地址模块读取 addressId 对应记录）
- [x] 订单非 UNPAID 不允许再次发起支付
- [x] 确认支付失败由系统决定（失败率/超时），取消支付不改变订单状态
