# 登录页面小人动画设计方案

## 一、效果描述

### 1.1 整体视觉效果

将登录页面左侧区域从当前的静态渐变背景改为**动态小人动画区域**，展示4个可爱的几何形状角色（代表非遗文化元素），配合表单输入产生有趣的交互反馈。

### 1.2 角色设计（融入非遗元素）

参考 CareerCompass 的角色设计，结合非遗商城主题进行本地化调整：

| 角色 | 形状 | 颜色 | 寓意 | 层级 |
|------|------|------|------|------|
| 紫色高矩形 | 高矩形（180×400px） | `#8B5CF6` 紫色 | 非遗传承的庄重感 | 最底层 (z-index: 1) |
| 深灰矩形 | 中矩形（120×310px） | `#374151` 深灰 | 历史的厚重感 | 中间层 (z-index: 2) |
| 橙色半圆 | 半圆形（240×200px） | `#F97316` 橙色 | 温暖的手工艺 | 前左层 (z-index: 3) |
| 黄色圆顶 | 圆顶矩形（140×230px） | `#FBBF24` 黄色 | 活力与创新 | 最前层 (z-index: 4) |

### 1.3 动画交互效果

| 交互场景 | 动画效果 | 触发条件 |
|----------|----------|----------|
| 👀 眼睛跟踪 | 瞳孔跟随鼠标移动 | 鼠标在页面移动 |
| 😊 自动眨眼 | 随机间隔眨眼（3-7秒） | 页面加载后持续 |
| 🎯 身体倾斜 | 角色身体跟随鼠标轻微倾斜 | 鼠标在页面移动 |
| ⌨️ 打字互动 | 角色们互相看对方 | 用户在账号/用户名输入框打字 |
| 🙈 偷看密码 | 紫色角色偷偷瞄向密码框 | 密码输入框显示明文且内容非空 |
| 🙊 遮挡姿势 | 紫色角色做"遮眼"动作 | 密码被隐藏时 |
| 🎨 角色切换 | 角色表情/姿态微调 | 登录/注册模式切换 |

## 二、实现思路

### 2.1 技术方案

**采用纯 Vue 3 + CSS 实现，不引入额外动画库**

理由：
- 性能最优（纯 CSS transform，GPU 加速）
- 包体积小，无需额外依赖
- 代码可控性强，易于调试和维护
- 与项目现有技术栈完美契合

### 2.2 组件拆分

```
frontend/src/
├── components/
│   └── AnimatedCharacters.vue    # 新增：小人动画组件
└── views/
    └── Login.vue                  # 修改：引入动画组件
```

### 2.3 核心实现逻辑

#### 2.3.1 眼睛跟踪鼠标
```javascript
// 计算瞳孔位置
const calculatePupilPosition = (eyeRef, mouseX, mouseY) => {
  const eye = eyeRef.value.getBoundingClientRect()
  const eyeCenterX = eye.left + eye.width / 2
  const eyeCenterY = eye.top + eye.height / 2
  
  const deltaX = mouseX - eyeCenterX
  const deltaY = mouseY - eyeCenterY
  const distance = Math.min(Math.sqrt(deltaX ** 2 + deltaY ** 2), maxDistance)
  const angle = Math.atan2(deltaY, deltaX)
  
  return {
    x: Math.cos(angle) * distance,
    y: Math.sin(angle) * distance
  }
}
```

#### 2.3.2 自动眨眼
```javascript
// 随机眨眼
const scheduleBlink = () => {
  const interval = Math.random() * 4000 + 3000 // 3-7秒
  setTimeout(() => {
    isBlinking.value = true
    setTimeout(() => {
      isBlinking.value = false
      scheduleBlink()
    }, 150) // 眨眼持续150ms
  }, interval)
}
```

#### 2.3.3 打字互动
```javascript
// 监听输入事件
const handleInputFocus = () => {
  isTyping.value = true
  clearTimeout(typingTimeout)
  typingTimeout = setTimeout(() => {
    isTyping.value = false
  }, 800)
}
```

### 2.4 样式实现要点

```scss
// 角色基础样式
.character {
  position: absolute;
  transition: transform 0.7s ease-in-out;
  transform-origin: bottom center;
  
  // 眼睛容器
  .eye {
    position: absolute;
    width: 20px;
    height: 20px;
    background: white;
    border-radius: 50%;
    
    .pupil {
      position: absolute;
      width: 10px;
      height: 10px;
      background: #1a1a1a;
      border-radius: 50%;
      transition: transform 0.1s ease-out;
    }
  }
  
  // 眨眼动画
  &.blinking .eye {
    transform: scaleY(0.1);
    transition: transform 0.1s ease-in-out;
  }
}
```

## 三、与当前项目的适配调整

### 3.1 表单字段映射

当前项目的登录/注册表单与 CareerCompass 不同，需要调整交互映射：

| 表单字段 | 动画响应 |
|----------|----------|
| 账号输入框 | 打字时角色互相看对方 |
| 用户名输入框 | 打字时角色互相看对方 |
| 用户类型选择 | 角色表情微微变化（可选） |
| 密码输入框 | 紫色角色偷看/遮挡 |
| 确认密码框 | 同密码框效果 |
| 验证码输入框 | 无特殊交互 |

### 3.2 布局适配

当前登录页面左侧宽度比例合适，只需替换内容区域：

```vue
<!-- Login.vue 修改 -->
<div class="login-left">
  <AnimatedCharacters 
    :isTyping="isTyping"
    :isPasswordVisible="isPasswordVisible"
    :isLogin="isLogin"
  />
</div>
```

### 3.3 主题适配

支持暗色模式切换：
- 暗色模式：角色颜色略微调暗，背景色更深
- 亮色模式：保持默认配色

### 3.4 响应式处理

- 桌面端（>768px）：显示完整动画
- 移动端（≤768px）：隐藏动画，保持原有渐变背景
