## 阶段三：后端业务逻辑层

### 3.1 DTO 类设计
- [ ] 创建 AnnouncementCreateRequest（新增公告：标题、富文本内容必填，状态、置顶可选）
- [ ] 创建 AnnouncementUpdateRequest（更新公告：所有字段可选）
- [ ] 创建 AnnouncementVO（公告返回：完整信息 + 时间字段）
- [ ] 创建 HeritageStoryCreateRequest（新增故事：标题、富文本内容必填，关联项目、状态、置顶可选）
- [ ] 创建 HeritageStoryUpdateRequest（更新故事：所有字段可选）
- [ ] 创建 HeritageStoryVO（故事返回：完整信息 + 关联项目名称 + 时间字段）

### 3.2 Service 层
- [ ] 创建 AnnouncementService 接口及实现类
  - [ ] createAnnouncement(AnnouncementCreateRequest) - 新增公告（仅管理员）
  - [ ] updateAnnouncement(Long id, AnnouncementUpdateRequest) - 更新公告（仅管理员）
  - [ ] deleteAnnouncement(Long id) - 删除公告（仅管理员）
  - [ ] getManagePage(PageQuery, Integer status) - 管理端分页查询（含草稿）
  - [ ] getPublishedPage(PageQuery) - 前台分页查询（仅已发布，置顶优先）
  - [ ] getDetail(Long id) - 公告详情

- [ ] 创建 HeritageStoryService 接口及实现类
  - [ ] createHeritageStory(HeritageStoryCreateRequest) - 新增故事（仅管理员）
  - [ ] updateHeritageStory(Long id, HeritageStoryUpdateRequest) - 更新故事（仅管理员）
  - [ ] deleteHeritageStory(Long id) - 删除故事（仅管理员）
  - [ ] getManagePage(PageQuery, Integer status, Long heritageProjectId) - 管理端分页查询（含草稿）
  - [ ] getPublishedPage(PageQuery) - 前台分页查询（仅已发布，置顶优先）
  - [ ] getDetail(Long id) - 故事详情

### 3.3 业务规则与校验
- [ ] 新增公告/故事必填校验（title、content 非空）
- [ ] 状态值校验（仅允许 0 或 1）
- [ ] 置顶值校验（仅允许 0 或 1）
- [ ] 非遗故事关联项目校验（如提供 heritageProjectId 则项目需存在）
- [ ] 前台查询自动过滤草稿（status = 1）
- [ ] 前台列表排序规则：is_top DESC, create_time DESC
- [ ] 富文本内容 HTML 消毒（过滤 <script>、onerror 等危险标签/属性，防 XSS）
