# 自动翻译性能优化方案

## 📊 现状分析

### 当前问题
- **首次翻译延迟**: 2-3 秒
- **用户感知**: 页面加载后需要等待明显延迟才能看到翻译结果

### 性能瓶颈分析

1. **后端串行处理** ⚠️ **主要瓶颈**
   - `TranslationController.translateBatch()` 方法对 n 条文本逐条调用百度 API
   - 单次翻译耗时：约 300-800ms
   - 10 条文本总耗时：3-8 秒（串行累加）
   - 代码位置：`backend/src/main/java/com/heritage/controller/TranslationController.java#L130-146`

2. **前端执行时机** ⚠️ **次要瓶颈**
   - DOM 扫描在页面完全渲染后才开始
   - 用户看到空白/加载中状态时间过长
   - 未区分首屏和屏外内容

3. **网络往返开销**
   - 批量接口虽然合并了请求，但后端仍是 n 次独立 API 调用
   - 没有充分利用百度翻译 API 的多段文本支持

## 💡 优化方案详情

### 方案一：后端批量翻译并行化（核心优化）

#### 问题分析
```java
// 当前实现 - 串行处理（伪代码）
for (String text : texts) {
    // 每次循环调用一次百度 API，耗时 300-800ms
    Map<String, Object> singleResult = doTranslate(text, from, to);
    translatedTexts.add(translated);
}
// 10 条文本总耗时 = 10 × 500ms = 5 秒
```

#### 优化方案
使用线程池并行翻译所有文本，利用 CompletableFuture 实现异步编排。

##### 1. 创建线程池配置
```java
@Configuration
public class TranslatorThreadPoolConfig {
    
    /**
     * 翻译任务专用线程池
     * 核心参数基于百度翻译 API QPS 限制和性能测试
     */
    @Bean(name = "translatorExecutor")
    public ExecutorService translatorExecutor() {
        return new ThreadPoolExecutor(
            5,                      // 核心线程数（同时处理 5 个翻译请求）
            20,                     // 最大线程数（高峰期可扩容到 20）
            60L,                    // 空闲线程存活时间（秒）
            TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),  // 阻塞队列容量
            new ThreadFactoryBuilder()
                .setNameFormat("translator-pool-%d")
                .setDaemon(true)
                .build(),
            new ThreadPoolExecutor.CallerRunsPolicy()  // 队列满时由调用线程执行
        );
    }
}
```

##### 2. 重构批量翻译接口
```java
@PostMapping("/batch")
public Map<String, Object> translateBatch(
        @RequestBody Map<String, Object> request) {
    
    Map<String, Object> result = new HashMap<>();
    
    try {
        List<String> texts = (List<String>) request.get("texts");
        String from = (String) request.getOrDefault("from", "zh");
        String to = (String) request.getOrDefault("to", "en");
        
        if (texts == null || texts.isEmpty()) {
            result.put("code", 200);
            result.put("data", new ArrayList<String>());
            return result;
        }
        
        // ✅ 并行翻译：为每个文本创建异步任务
        List<CompletableFuture<String>> futures = texts.stream()
            .map(text -> CompletableFuture.supplyAsync(() -> {
                try {
                    if (text == null || text.trim().isEmpty()) {
                        return "";
                    }
                    
                    // 复用已有的 doTranslate 方法
                    Map<String, Object> singleResult = doTranslate(text, from, to);
                    if ((Integer) singleResult.get("code") == 200) {
                        Map<String, Object> data = (Map<String, Object>) singleResult.get("data");
                        List<Map<String, String>> transResult = (List<Map<String, String>>) data.get("trans_result");
                        return transResult.get(0).get("dst");
                    } else {
                        return text;  // 翻译失败返回原文
                    }
                } catch (Exception e) {
                    log.error("单条翻译失败", e);
                    return text;
                }
            }, translatorExecutor))  // 使用自定义线程池
            .collect(Collectors.toList());
        
        // 等待所有翻译完成
        List<String> translatedTexts = futures.stream()
            .map(CompletableFuture::join)
            .collect(Collectors.toList());
        
        result.put("code", 200);
        result.put("data", translatedTexts);
        
    } catch (Exception e) {
        log.error("批量翻译异常", e);
        result.put("code", 500);
        result.put("message", "批量翻译失败：" + e.getMessage());
    }
    
    return result;
}
```

### 方案二：首屏优先翻译（体验优化）

#### 问题分析
- 当前实现等待整个页面 DOM 加载完成才开始翻译
- 用户看到的加载时间 = 页面渲染时间 + 全部翻译时间
- 首屏内容和屏外内容一起翻译，无法优先展示关键信息

#### 优化方案
分阶段翻译策略：首屏内容立即翻译，屏外内容滚动时翻译。

##### 1. 新增视口检测工具函数
```javascript
// frontend/src/utils/autoTranslate.js

/**
 * 判断元素是否在视口内（可见区域）
 * @param {Element} element - DOM 元素
 * @returns {boolean} 是否在视口内
 */
export function isInViewport(element) {
  if (!element) return false
  
  const rect = element.getBoundingClientRect()
  const viewportHeight = window.innerHeight || document.documentElement.clientHeight
  
  // 元素至少 50% 在视口内
  return (
    rect.top >= -rect.height / 2 &&
    rect.bottom <= viewportHeight + rect.height / 2
  )
}

/**
 * 获取所有在视口内的文本节点
 * @param {Node[]} textNodes - 所有文本节点
 * @returns {Node[]} 在视口内的文本节点
 */
export function filterViewportTextNodes(textNodes) {
  return textNodes.filter(node => {
    const parent = node.parentElement
    if (!parent) return false
    
    // 检查父元素是否在视口内
    return isInViewport(parent)
  })
}
```

##### 2. 重构主翻译流程为两阶段
```javascript
// frontend/src/utils/autoTranslate.js

/**
 * 翻译页面到英文（两阶段优化版）
 * @returns {Promise<void>}
 */
export async function translatePageToEnglish() {
  console.log('🚀 开始自动翻译页面（首屏优先）...')
  
  // === 第一阶段：立即翻译首屏内容 ===
  console.time('首屏翻译耗时')
  
  // 扫描全页面
  const { textNodes: allTextNodes, attributeNodes: allAttributeNodes } = scanAllChineseContent()
  console.log(`找到 ${allTextNodes.length} 个文本节点，${allAttributeNodes.length} 个属性需要翻译`)
  
  if (allTextNodes.length === 0 && allAttributeNodes.length === 0) {
    console.log('未找到需要翻译的中文内容')
    return
  }
  
  // 筛选首屏可见内容
  const viewportTextNodes = filterViewportTextNodes(allTextNodes)
  const viewportAttributeNodes = allAttributeNodes.filter(attr => 
    isInViewport(attr.element)
  )
  
  console.log(`✨ 首屏内容：${viewportTextNodes.length} 个文本节点，${viewportAttributeNodes.length} 个属性`)
  
  // 提取首屏文本并翻译
  const viewportTexts = [
    ...viewportTextNodes.map(node => cleanText(node.nodeValue)),
    ...viewportAttributeNodes.map(attr => cleanText(attr.originalValue))
  ]
  
  // 批量翻译首屏内容
  const viewportTranslationMap = await batchTranslate(viewportTexts)
  
  // 替换首屏文本节点
  let translatedCount = 0
  viewportTextNodes.forEach((node) => {
    const originalText = cleanText(node.nodeValue)
    const translatedText = viewportTranslationMap.get(originalText)
    
    if (translatedText && translatedText !== originalText) {
      originalTextCache.set(node, originalText)
      node.nodeValue = translatedText
      translatedCount++
    }
  })
  
  // 替换首屏属性值
  viewportAttributeNodes.forEach((attrInfo) => {
    const originalValue = cleanText(attrInfo.originalValue)
    const translatedValue = viewportTranslationMap.get(originalValue)
    
    if (translatedValue && translatedValue !== originalValue) {
      originalTextCache.set(`${attrInfo.element.tagName}-${attrInfo.attributeName}`, attrInfo.originalValue)
      attrInfo.element.setAttribute(attrInfo.attributeName, translatedValue)
      translatedCount++
    }
  })
  
  console.log(`✅ 首屏翻译完成，翻译 ${translatedCount} 个内容`)
  console.timeEnd('首屏翻译耗时')
  
  // === 第二阶段：延迟翻译屏外内容 ===
  console.time('屏外翻译耗时')
  
  // 过滤出屏外节点
  const offscreenTextNodes = allTextNodes.filter(n => !viewportTextNodes.includes(n))
  const offscreenAttributeNodes = allAttributeNodes.filter(n => !viewportAttributeNodes.includes(n))
  
  if (offscreenTextNodes.length > 0 || offscreenAttributeNodes.length > 0) {
    // 使用 requestIdleCallback 或 setTimeout 延迟处理，避免阻塞用户交互
    if (typeof requestIdleCallback !== 'undefined') {
      requestIdleCallback(() => {
        translateOffscreenContent(offscreenTextNodes, offscreenAttributeNodes)
      })
    } else {
      setTimeout(() => {
        translateOffscreenContent(offscreenTextNodes, offscreenAttributeNodes)
      }, 100)  // 100ms 延迟
    }
  }
}

/**
 * 翻译屏外内容（辅助函数）
 */
async function translateOffscreenContent(textNodes, attributeNodes) {
  if (textNodes.length === 0 && attributeNodes.length === 0) {
    return
  }
  
  console.log(`📝 开始翻译屏外内容：${textNodes.length} 个文本节点`)
  
  const offscreenTexts = [
    ...textNodes.map(node => cleanText(node.nodeValue)),
    ...attributeNodes.map(attr => cleanText(attr.originalValue))
  ]
  
  const translationMap = await batchTranslate(offscreenTexts)
  
  let translatedCount = 0
  textNodes.forEach((node) => {
    const originalText = cleanText(node.nodeValue)
    const translatedText = translationMap.get(originalText)
    
    if (translatedText && translatedText !== originalText) {
      originalTextCache.set(node, originalText)
      node.nodeValue = translatedText
      translatedCount++
    }
  })
  
  attributeNodes.forEach((attrInfo) => {
    const originalValue = cleanText(attrInfo.originalValue)
    const translatedValue = translationMap.get(originalValue)
    
    if (translatedValue && translatedValue !== originalValue) {
      originalTextCache.set(`${attrInfo.element.tagName}-${attrInfo.attributeName}`, attrInfo.originalValue)
      attrInfo.element.setAttribute(attrInfo.attributeName, translatedValue)
      translatedCount++
    }
  })
  
  console.log(`✅ 屏外翻译完成，翻译 ${translatedCount} 个内容`)
  console.timeEnd('屏外翻译耗时')
}
```

##### 3. （可选）添加滚动触发翻译
```javascript
// 对于长列表或无限滚动页面，可以添加滚动监听
let hasScrolledTranslate = false

export function enableScrollTranslation() {
  if (hasScrolledTranslate) return
  
  let ticking = false
  window.addEventListener('scroll', () => {
    if (!ticking) {
      window.requestAnimationFrame(() => {
        // 检测是否有新的内容进入视口需要翻译
        const { textNodes } = scanAllChineseContent()
        const unseenNodes = textNodes.filter(node => {
          const parent = node.parentElement
          return parent && 
                 isInViewport(parent) && 
                 !originalTextCache.has(node)  // 尚未翻译
        })
        
        if (unseenNodes.length > 0) {
          console.log(`滚动发现新内容：${unseenNodes.length} 个节点`)
          // 翻译新出现的内容
          const texts = unseenNodes.map(node => cleanText(node.nodeValue))
          batchTranslate(texts).then(map => {
            unseenNodes.forEach(node => {
              const originalText = cleanText(node.nodeValue)
              const translatedText = map.get(originalText)
              if (translatedText) {
                originalTextCache.set(node, originalText)
                node.nodeValue = translatedText
              }
            })
          })
        }
        
        ticking = false
      })
      ticking = true
    }
  })
  
  hasScrolledTranslate = true
}
```

## ⚠️ 注意事项

### 后端注意事项

1. **线程池大小选择**
   - 基于百度翻译 API QPS 限制（普通版 QPS=1，高级版 QPS=10+）
   - 根据实际购买的 API 版本调整核心线程数
   - 避免超过 QPS 限制导致请求被拒绝

2. **异常处理**
   - 单个翻译失败不影响其他任务
   - 添加重试机制（可选）
   - 记录失败日志便于排查

3. **资源释放**
   - 应用关闭时优雅关闭线程池
   - 避免线程泄漏

### 前端注意事项

1. **视口检测性能**
   - `getBoundingClientRect()` 会触发重排，避免频繁调用
   - 使用 `requestAnimationFrame` 或节流优化

2. **缓存一致性**
   - 确保缓存键唯一性
   - 定期清理过期缓存

3. **用户体验**
   - 首屏翻译完成后立即展示
   - 屏外翻译不要阻塞滚动等交互
   - 考虑添加翻译进度提示（可选）
