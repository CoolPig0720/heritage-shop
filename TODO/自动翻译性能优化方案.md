# 自动翻译性能优化方案

## 📊 现状分析

### 当前问题
- **首次翻译延迟**: 2-3 秒
- **用户感知**: 页面加载后需要等待明显延迟才能看到翻译结果

### 性能瓶颈分析

1. **后端串行处理** ⚠️ **主要瓶颈**
   - `TranslationController.translateBatch()` 方法对 n 条文本逐条调用百度 API
   - 单次翻译耗时：约 300-800ms
   - 10 条文本总耗时：3-8 秒（串行累加）
   - 代码位置：`backend/src/main/java/com/heritage/controller/TranslationController.java#L130-146`

2. **前端执行时机** ⚠️ **次要瓶颈**
   - DOM 扫描在页面完全渲染后才开始
   - 用户看到空白/加载中状态时间过长
   - 未区分首屏和屏外内容

3. **网络往返开销**
   - 批量接口虽然合并了请求，但后端仍是 n 次独立 API 调用
   - **未使用百度翻译 API 的多段文本功能（核心优化点）**

### ⚠️ 重要约束：普通版 API 限制

当前使用的是**百度翻译普通版 API**：
- **QPS 限制 = 1**（每秒仅允许 1 次请求）
- 超过限制会返回 **54003 错误**（Invalid Request Frequency）
- **线程池并行方案不可用**（会被限流）

## 💡 优化方案详情

### 方案一：百度 API 多段文本合并（核心优化 ⭐⭐⭐）

#### 问题分析
```java
// 当前实现 - 串行处理
for (String text : texts) {
    Map<String, Object> singleResult = doTranslate(text, from, to);  // N 次 API 调用
    translatedTexts.add(translated);
}
// 10 条文本 = 10 次 API 调用 = 5 秒
```

#### 优化方案
百度翻译 API 原生支持**多段文本翻译**：将多条文本用换行符 `\n` 连接，单次 API 调用即可翻译全部内容。

**官方文档说明**：
> q 参数支持传入多段文本，各段文本用换行符 `\n` 分隔，翻译结果也用 `\n` 分隔返回。

#### 代码实现

```java
/**
 * 批量翻译 - 多段文本合并版本
 * 利用百度API的多段文本功能，单次调用翻译多条文本
 */
@PostMapping("/batch")
public Map<String, Object> translateBatch(
        @RequestBody Map<String, Object> request) {
    
    Map<String, Object> result = new HashMap<>();
    
    try {
        List<String> texts = (List<String>) request.get("texts");
        String from = (String) request.getOrDefault("from", "zh");
        String to = (String) request.getOrDefault("to", "en");
        
        if (texts == null || texts.isEmpty()) {
            result.put("code", 200);
            result.put("data", new ArrayList<String>());
            return result;
        }
        
        // 过滤空文本，记录原始位置
        List<Integer> validIndices = new ArrayList<>();
        List<String> validTexts = new ArrayList<>();
        for (int i = 0; i < texts.size(); i++) {
            String text = texts.get(i);
            if (text != null && !text.trim().isEmpty()) {
                validIndices.add(i);
                validTexts.add(text.trim());
            }
        }
        
        if (validTexts.isEmpty()) {
            result.put("code", 200);
            result.put("data", texts);  // 全部为空，返回原数组
            return result;
        }
        
        // ✅ 核心：将多条文本用换行符连接
        String combinedText = String.join("\n", validTexts);
        
        log.info("批量翻译：{} 条文本合并为 1 次 API 调用", validTexts.size());
        
        // 单次 API 调用
        Map<String, Object> singleResult = doTranslate(combinedText, from, to);
        
        List<String> translatedTexts = new ArrayList<>(texts);
        
        if ((Integer) singleResult.get("code") == 200) {
            Map<String, Object> data = (Map<String, Object>) singleResult.get("data");
            List<Map<String, String>> transResult = (List<Map<String, String>>) data.get("trans_result");
            
            // 获取翻译结果，按换行符分割
            String translated = transResult.get(0).get("dst");
            String[] translatedParts = translated.split("\n");
            
            // 按原始位置填充结果
            for (int i = 0; i < validIndices.size(); i++) {
                int originalIndex = validIndices.get(i);
                String part = i < translatedParts.length ? translatedParts[i] : validTexts.get(i);
                translatedTexts.set(originalIndex, part);
            }
        } else {
            // 翻译失败时返回原文
            for (int i = 0; i < validIndices.size(); i++) {
                translatedTexts.set(validIndices.get(i), validTexts.get(i));
            }
        }
        
        result.put("code", 200);
        result.put("data", translatedTexts);
        
    } catch (Exception e) {
        log.error("批量翻译异常", e);
        result.put("code", 500);
        result.put("message", "批量翻译失败：" + e.getMessage());
    }
    
    return result;
}
```

#### 注意事项

1. **单次请求字符数限制**：
   - 普通版：单次最大 2000 字符
   - 需要检查合并后的总字符数，超过限制时需分批处理

2. **分批处理逻辑**：
```java
// 如果合并后超过 2000 字符，需要分批
private List<String> batchTranslateWithLimit(List<String> texts, String from, String to) {
    List<String> results = new ArrayList<>();
    List<String> currentBatch = new ArrayList<>();
    int currentLength = 0;
    
    for (String text : texts) {
        if (currentLength + text.length() + 1 > 1900) {  // 预留安全余量
            // 当前批次已满，先翻译
            results.addAll(translateCombined(currentBatch, from, to));
            currentBatch.clear();
            currentLength = 0;
        }
        currentBatch.add(text);
        currentLength += text.length() + 1;  // +1 for \n
    }
    
    // 处理最后一批
    if (!currentBatch.isEmpty()) {
        results.addAll(translateCombined(currentBatch, from, to));
    }
    
    return results;
}
```

#### 预期收益
- **10 条文本**：从 10 次 API 调用 → **1 次**（提升 90%）
- **20 条文本**：从 20 次 API 调用 → **1-2 次**（提升 90-95%）
- **完美适配普通版 QPS 限制**：不会触发频率限制

### 方案二：前端缓存持久化（体验优化 ⭐⭐）

#### 问题分析
当前缓存仅在内存中，页面刷新后丢失：
- 用户刷新页面需要重新翻译
- 相同页面多次访问重复调用 API

#### 优化方案
使用 `localStorage` 持久化翻译缓存。

##### 1. 修改前端缓存逻辑
```javascript
// frontend/src/utils/autoTranslate.js

// 持久化缓存键名
const CACHE_KEY = 'translation_cache'
const CACHE_EXPIRE_DAYS = 7  // 缓存有效期 7 天

// 从 localStorage 加载缓存
function loadCacheFromStorage() {
  try {
    const stored = localStorage.getItem(CACHE_KEY)
    if (stored) {
      const { data, expireTime } = JSON.parse(stored)
      if (Date.now() < expireTime) {
        const map = new Map(Object.entries(data))
        map.forEach((value, key) => translationCache.set(key, value))
        console.log(`从缓存加载 ${map.size} 条翻译记录`)
      } else {
        localStorage.removeItem(CACHE_KEY)  // 缓存过期，清除
      }
    }
  } catch (e) {
    console.warn('加载翻译缓存失败:', e)
  }
}

// 保存缓存到 localStorage
function saveCacheToStorage() {
  try {
    const data = Object.fromEntries(translationCache)
    const expireTime = Date.now() + CACHE_EXPIRE_DAYS * 24 * 60 * 60 * 1000
    localStorage.setItem(CACHE_KEY, JSON.stringify({ data, expireTime }))
  } catch (e) {
    console.warn('保存翻译缓存失败:', e)
  }
}

// 在 batchTranslate 函数中调用
async function batchTranslate(texts) {
  // ... 翻译逻辑 ...
  
  // 翻译完成后保存缓存
  saveCacheToStorage()
}
```

##### 2. 页面加载时初始化
```javascript
// 在模块加载时执行
loadCacheFromStorage()
```

#### 预期收益
- **二次访问延迟**：从 2-3 秒 → **0 秒**
- **API 调用减少**：相同内容不重复调用

### 方案三：首屏优先翻译（体验优化 ⭐）

#### 问题分析
- 当前实现等待整个页面 DOM 加载完成才开始翻译
- 首屏内容和屏外内容一起翻译，用户等待时间过长

#### 优化方案
使用 `IntersectionObserver` API 实现视口检测，优先翻译可见区域内容。

##### 1. 添加视口检测工具函数
```javascript
// frontend/src/utils/autoTranslate.js

/**
 * 使用 IntersectionObserver 检测元素是否在视口内
 * @param {Element} element - DOM 元素
 * @returns {Promise<boolean>} 是否在视口内
 */
function isInViewport(element) {
  return new Promise((resolve) => {
    const observer = new IntersectionObserver(
      (entries) => {
        observer.disconnect()
        resolve(entries[0].isIntersecting)
      },
      { threshold: 0.1 }  // 10% 可见即认为在视口内
    )
    observer.observe(element)
  })
}

/**
 * 快速同步检测（不触发重排的简化版本）
 */
function isInViewportSync(element) {
  const rect = element.getBoundingClientRect()
  const windowHeight = window.innerHeight || document.documentElement.clientHeight
  return rect.top < windowHeight && rect.bottom > 0
}
```

##### 2. 分阶段翻译流程
```javascript
export async function translatePageToEnglish() {
  console.log('🚀 开始自动翻译页面（首屏优先）...')
  console.time('首屏翻译耗时')
  
  const { textNodes, attributeNodes } = scanAllChineseContent()
  
  if (textNodes.length === 0 && attributeNodes.length === 0) {
    return
  }
  
  // ✅ 分离首屏和屏外内容
  const viewportNodes = textNodes.filter(node => {
    const parent = node.parentElement
    return parent && isInViewportSync(parent)
  })
  
  const viewportAttrs = attributeNodes.filter(attr => 
    isInViewportSync(attr.element)
  )
  
  console.log(`✨ 首屏内容：${viewportNodes.length} 个文本节点`)
  
  // 第一阶段：翻译首屏内容
  const viewportTexts = [
    ...viewportNodes.map(node => cleanText(node.nodeValue)),
    ...viewportAttrs.map(attr => cleanText(attr.originalValue))
  ]
  
  const viewportMap = await batchTranslate(viewportTexts)
  
  // 替换首屏文本
  viewportNodes.forEach(node => {
    const original = cleanText(node.nodeValue)
    const translated = viewportMap.get(original)
    if (translated && translated !== original) {
      originalTextCache.set(node, original)
      node.nodeValue = translated
    }
  })
  
  viewportAttrs.forEach(attr => {
    const original = cleanText(attr.originalValue)
    const translated = viewportMap.get(original)
    if (translated && translated !== original) {
      originalTextCache.set(`${attr.element.tagName}-placeholder`, attr.originalValue)
      attr.element.setAttribute(attr.attributeName, translated)
    }
  })
  
  console.timeEnd('首屏翻译耗时')
  
  // 第二阶段：延迟翻译屏外内容
  const offscreenNodes = textNodes.filter(n => !viewportNodes.includes(n))
  const offscreenAttrs = attributeNodes.filter(a => !viewportAttrs.includes(a))
  
  if (offscreenNodes.length > 0) {
    // 使用 requestIdleCallback 在浏览器空闲时翻译
    requestIdleCallback(() => {
      console.log('📝 翻译屏外内容...')
      translateOffscreen(offscreenNodes, offscreenAttrs)
    }, { timeout: 2000 })
  }
}

async function translateOffscreen(textNodes, attributeNodes) {
  const texts = [
    ...textNodes.map(node => cleanText(node.nodeValue)),
    ...attributeNodes.map(attr => cleanText(attr.originalValue))
  ]
  
  const map = await batchTranslate(texts)
  
  textNodes.forEach(node => {
    const original = cleanText(node.nodeValue)
    const translated = map.get(original)
    if (translated && translated !== original) {
      originalTextCache.set(node, original)
      node.nodeValue = translated
    }
  })
  
  attributeNodes.forEach(attr => {
    const original = cleanText(attr.originalValue)
    const translated = map.get(original)
    if (translated && translated !== original) {
      attr.element.setAttribute(attr.attributeName, translated)
    }
  })
}
```

#### 预期收益
- **用户感知延迟**：从 3 秒 → **0.3-0.5 秒**（首屏内容立即可见）
- **交互流畅度**：屏外翻译在后台进行，不影响用户浏览

## ⚠️ 注意事项

### 后端注意事项

1. **字符数限制**
   - 普通版单次最大 2000 字符
   - 合并文本时需检查总长度，超限自动分批
   - 建议预留安全余量（如 1900 字符）

2. **换行符处理**
   - 原文中的换行符需要转义或替换
   - 翻译结果按 `\n` 分割时需注意数量对应

3. **异常处理**
   - 单次翻译失败时返回原文
   - 记录失败日志便于排查

### 前端注意事项

1. **缓存管理**
   - localStorage 有容量限制（约 5MB）
   - 设置缓存过期时间，定期清理
   - 考虑缓存容量告警机制

2. **视口检测性能**
   - `getBoundingClientRect()` 会触发重排
   - 只在首屏检测时调用一次
   - 避免在滚动事件中频繁调用

3. **Vue 响应式兼容**
   - 直接修改 DOM 文本节点不会触发 Vue 响应式更新
   - 翻译内容应是静态文本，不应包含动态绑定
   - 恢复中文时需确保 DOM 节点未被 Vue 重新渲染
